### Phase 9: Taxon evidence and curation

- Create `boldgenotyper/taxon_evidence.py`:
  `compute_evidence(haplotypes: pd.DataFrame, records: pd.DataFrame, distance_by_id: pd.DataFrame, tree_path: Optional[Path]) -> pd.DataFrame`
  returning one row per `haplotype_id` with the evidence columns of design §2
  (`nearest_species_haplotype`, `nearest_species_taxon`, `nearest_species_distance`,
  `taxon_max_within_distance`, `within_taxon_spread`, `member_bins`, `bin_taxon`,
  `label_sources`, `tree_sister_taxon`, `tree_sister_support`, `suggested_sp`,
  `suggestion_basis`); `label_source(processid: str, inst: str, insdc_acs: str) -> str`.

  `load_curation(path: Path) -> pd.DataFrame` (validates columns);
  `match_curation(curation: pd.DataFrame, haplotypes: pd.DataFrame, sequences: Dict[str, str]) -> Tuple[pd.DataFrame, pd.DataFrame]`
  (applied rows with `haplotype_id`; rows not applied with a reason);
  `apply_curation(haplotypes: pd.DataFrame, applied: pd.DataFrame) -> pd.DataFrame`

  `label_conflicts.csv` gain the new columns; `run_readme` documents them.

  curated haplotype (`call_basis`, flag `curated_taxa_disagree`).

  with a 4/4 label tie, one project behind one label, a shared BIN and a nearest species
