reference run. Two choices made here, for review:

- The writers go in a new `boldgenotyper/query_outputs.py` rather than growing
  `haplotype_query.py` (1,017 lines); `haplotype_query.py` keeps alignment and the query
  loop.
- Figures are written for every v2 run-folder reference, each when the reference has what
  it needs (a tree, regions, dates, mapped records); `--query-metadata` adds the queries'
  own locations, regions and dates. The design gated all figures on `--query-metadata`,
  but placing queries on the tree needs no metadata, and the matched haplotypes' maps,
  regions and dates are useful without it.

Figure pages follow the paging pattern Phase 11 will generalize: a multi-page PDF
(`query_figures/<name>.pdf`) and one SVG per page (`query_figures/<name>/<page>.svg`),
with `svg.fonttype = "none"` so labels stay text. Figure failures are logged and listed
in `query_provenance.json` (`warnings`); the query still exits 0.

## Phase 12: Report

Design §5. The report becomes a package, `boldgenotyper/report/`, generated **after** the
output layout from the final run folder (tables, figure manifests) and the in-memory
provenance; it reads no staging file. `reports.py` keeps only `compute_assignment_summary`,
`generate_assignment_summary` and their column lists. Choices made here, for review:

- A `report/data.py` loads the run folder once (`RunData`); `insights.key_findings` takes a
  `RunData` instead of `(run_dir, provenance)`.
- The current Parameters section is folded into Overview (key settings) and Methods; the full
  configuration stays in `run_provenance.json`.
- Label conflicts are shown per haplotype and conflicting label (records, majority label and
  fraction, nearest haplotype carrying the label and its distance), most records first; the
  per-record list stays in `label_conflicts.csv`.
- The page keeps `<div class="section" id="section-<name>">` so the existing report tests
  keep working.
- The report is written before the run README, so the README documents `report.html`; the
  report's file list covers the README.

| `boldgenotyper/report/__init__.py` | `generate_html_report(run_dir, organism, provenance, version=None) -> Path` |
