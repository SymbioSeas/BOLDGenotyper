    removed = REMOVED_FLAGS.get(command, {})

## Phase 9: Taxon evidence and curation

Design §2. The taxon rule is unchanged. Curation is applied in Phase 5 of the pipeline,
right after `utils.assign_consensus_taxonomy`, so curated taxa reach the display labels and
every later step. Evidence is computed in Phase 13, when `haplotypes.csv` is built (the tree
exists by then). Distances use `dereplication.distances_to_references` on the aligned core
sequences, the definition behind `nearest_distance` and the label-conflict evidence.

### File structure

| File | Responsibility |
|---|---|
| `boldgenotyper/taxon_curation.py` (new) | load and validate a curation file; match rows to haplotypes; apply them to a taxonomy table |
| `boldgenotyper/taxon_evidence.py` (new) | evidence columns and suggested taxa |
| `boldgenotyper/cli.py` | `--taxon-curation` (pipeline and query); apply in Phase 5; evidence in Phase 13; provenance |
| `boldgenotyper/quality_control.py` | label conflicts relative to a curated taxon; `haplotype_taxon`, `assignment_source` in `label_conflicts.csv` |

| `boldgenotyper/query_assignment.py`, `haplotype_query.py` | haplotype taxa in species calls; `call_basis` |
| `boldgenotyper/run_readme.py` | definitions of the new columns |

**Interfaces (produces):**
- `EVIDENCE_COLUMNS` (design §2 order); `BIN_MAJORITY = 0.70`
- `label_source(processid, inst="", insdc_acs="") -> str`: GenBank-mined records (`inst` contains "genbank") → `GenBank:<accession letters + first 3 digits>`; otherwise the processid's leading letters (BOLD project code).
