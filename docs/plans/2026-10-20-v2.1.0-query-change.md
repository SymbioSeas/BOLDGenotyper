# BOLDGenotyper 2.1.0: compare a query over the part the haplotype core covers

**Status (2026-10-20): done on `release/v2.1.0`, awaiting review before the tag.**

**Why.** Haplotypes are defined on a core region of the alignment. In some datasets the core
starts tens of bases into the barcode: about 54 bp in an order-level shark dataset, where
many records start late. A 5' mini-barcode (barcode start to ~127 bp) then hangs over the
core's start by ~54 bases. Its overlap with any haplotype covered 73/126 = 58% of the query,
below `--min-query-coverage` (0.95), so it was never eligible. Every such query got no call.

**Change (query side only).**
- `query_overhang`: query bases beyond a haplotype's own ends (before the overlap where the
  haplotype has no bases before it, or after it where the haplotype has none after it).
- `compared_coverage` = query bases in the overlap / min(query length − overhang,
  haplotype length). Eligibility uses it, with a minimum of `--min-overlap-length` (60)
  bases compared.
- `overlap_coverage` keeps its 2.0.0 meaning. Giving it the new meaning made an unrelated
  sequence touching a haplotype's end over 4 bases report coverage 1.0.
- Flags `compared_over_part` (the best match covers neither the whole query nor the whole
  haplotype) and `short_overlap`.

**Checks.**
- Full suite: 537 passed, 5 skipped, 0 failed.
- A pipeline run on 2.0.0 and on this branch: 11 result files, all identical.
- 199 mini-barcode queries (Sphyrnidae, as amplified, 54 bp before the core): with 2.0.0,
  none got a call; with this branch, 199 species calls, all right (73 bp compared; 167
  haplotype sets, 32 single haplotypes).
- 221 full-length queries of the same fold: `query_calls.csv` identical on 2.0.0 and this
  branch; `query_candidates.csv` identical apart from the two new columns.

**Also on this branch** (found while drafting the tool paper's label maps and preliminary runs):
- `boldgenotyper-labels`: WoRMS subgenus forms are no longer suggested as synonyms; a request
  that times out is retried (3 tries).
- The label composition heatmap (a staging figure) is skipped above 20,000 cells: a full
  family-level download was killed for memory there.
