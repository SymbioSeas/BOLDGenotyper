# BOLDGenotyper 2.3.1: threads for the record and divergence alignments

**Status (2026-10-25): done on `release/v2.3.1`, awaiting review before the tag.**

**Why.** The tool paper's runtime benchmark (supplement S3; Pieridae subsamples and the full
set, `--threads 8`) showed CPU time about equal to wall time in every run: the pipeline ran
on one core. `--threads` (`cfg.n_threads`) reached only the tree (`build_phylogeny`). The
MAFFT alignment of the records (`dereplication.run_mafft_alignment`, called from
`identify_haplotypes`) and of the haplotypes for the divergence step
(`divergence_analysis.align_consensus_sequences`) were called without `--thread`. The
record alignment is the longest step of a large run (18.5 of 39 min on 20,926 Pieridae
records). The README already said `--threads` sets the cores MAFFT uses.

**Change.** `run_mafft_alignment`, `identify_haplotypes`, `align_consensus_sequences` and
`generate_divergence_analysis` take `threads` (default 1, which runs the 2.3.0 command, with no
`--thread`); a number below 1 is an error in `run_mafft_alignment`. The pipeline passes
`cfg.n_threads` to both. `boldgenotyper-sweep` passes its `--threads` into each threshold's run,
so its alignments are threaded too; the thresholds still run one after another.

**Not done.** FastTree runs on one thread (the OpenMP build is not used). The error filter's
pairwise distances (9.7 of 39 min on the full Pieridae run) run in one process.

**Calls made here (for Steph's review).** `--thread N` is passed only when N > 1, so a
one-thread run is the 2.3.0 command exactly. The default of `--threads` stays 4, so a run
without the flag now aligns on 4 threads.

**Checks.**
- MAFFT 7.526 `--auto` on the QC-passed records of two Pieridae subsamples: 887 records, 4 s
  on one thread and 2 s on 8; 8,936 records, 203 s and 34 s; byte-identical alignments.
- Tests: `tests/test_alignment_threads.py`. The commands carry `--thread N` for N > 1 and
  not for 1, for both alignments; threads below 1 refused; `identify_haplotypes` and
  `generate_divergence_analysis` hand their threads on. End to end, a synthetic run with
  `n_threads=2` passes 2 to both alignments, and its 11 result files (records, haplotypes,
  the divergence alignment and distances among them) are byte-identical to a one-thread run.
- The September 2026 Carcharhiniformes download (9,785 rows), as run on 2.3.0 for the paper's
  supplement S4 (`--genetic-code 2 --singleton-distance 0.015`, its label map, no tree,
  `--threads 8`): 3 min 13 s on this branch against 5 min 47 s on 2.3.0, and all 13 result
  files (CSV, FASTA, TXT) byte-identical.
- Suite: 564 passed, 8 skipped (558 + 6 new).
