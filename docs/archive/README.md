## Why Archived?

These documents served their purpose during development but:

1. Information has been integrated into user-facing documentation (README.md, guides)
2. Features have been implemented and documented elsewhere
3. Content is now outdated or superseded by newer documents
4. Not relevant for end-users or new contributors
